코드사수

개인정보처리방침

시행일: 2026년 10월 15일 (10월 14일 처음 시행, 10월 15일 알림 항목 추가)

코드사수(이하 "서비스")는 개인이 운영하는 베타 단계의 학습 서비스예요. 서비스는 학습에 필요한 최소한의 정보만 받고, 아래와 같이 처리해요.

1. 받는 정보

언제받는 정보
이메일로 가입할 때이메일 주소, 비밀번호(암호화해서 저장하며 운영자도 원래 비밀번호를 볼 수 없어요)
구글 계정으로 로그인할 때구글 계정의 이메일 주소와 이름
매일 알림을 켤 때알림 시각, 브라우저가 만든 알림 받는 주소와 암호화 키(이 주소로만 알림을 보낼 수 있어요), 알림을 보낸 날과 알림을 눌렀는지 여부
레슨을 풀 때푼 레슨, 고른 답과 정답 여부, 걸린 시간, 사수 힌트 요청 기록과 힌트 내용
서비스를 쓰는 동안 자동으로접속 기록(접속 시각, IP 주소, 브라우저 정보), 로그인 유지를 위한 쿠키

가입하지 않고 첫 레슨을 풀면 이메일 없이 브라우저 쿠키로만 풀이 기록을 묶어요.

2. 쓰는 목적

  • 로그인과 계정 관리
  • 학습 기록, 이번 주 목표, 매일 알림 같은 서비스 기능 제공
  • 오류 해결과 서비스 개선
  • 베타 테스트 결과 분석 (개인을 알아볼 수 없는 통계로만 정리해요)

3. 보관 기간

베타 결과 분석이 끝나는 2027년 1월 6일까지 보관하고, 그 뒤에는 지체 없이 삭제해요. 그 전이라도 삭제를 요청하면 바로 지워요. 서버 접속 기록은 클라우드 서비스의 로그 보관 기간이 지나면 자동으로 지워져요.

4. 다른 곳에 주는 정보

받은 정보를 다른 사람이나 회사에 팔거나 넘기지 않아요. 다만 서비스를 운영하려고 아래 서비스를 이용해요.

이용하는 곳하는 일
Google Cloud (서울 지역)서버 운영과 접속 기록 보관
Supabase (서울 지역)계정과 학습 기록 데이터베이스
Google구글 계정 로그인
브라우저 알림 서비스 (Google·Apple·Mozilla·Microsoft)매일 알림 전달. 알림 내용은 암호화해서 보내 중간에서 읽을 수 없어요. 알림을 켠 경우에만 이용해요.
OpenAI (미국)사수 힌트 만들기. 문제와 레슨 내용만 보내고, 이메일·이름 같은 사용자 정보는 보내지 않아요.

5. 내 정보에 대한 권리

알림은 학습 기록 화면의 "이 기기 알림 끄기"로 언제든 끌 수 있고, 끄면 그 기기의 알림 주소를 지워요.

내 정보를 보거나, 고치거나, 지우거나(탈퇴), 처리를 멈춰 달라고 언제든 요청할 수 있어요. 아래 이메일로 보내 주시면 확인 후 바로 처리할게요.

6. 쿠키

로그인 유지와 보안(위조 요청 방지)을 위한 쿠키만 써요. 광고나 방문 분석용 쿠키는 쓰지 않아요.

7. 안전하게 지키는 방법

  • 모든 접속은 암호화(HTTPS)해요.
  • 비밀번호는 암호화해서 저장해요.
  • 데이터베이스는 외부에서 바로 읽을 수 없게 막아 두었어요.
